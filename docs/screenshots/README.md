# Project Screenshots

This directory contains selected screenshots documenting the deployment, configuration, and testing of the automated AWS backup and audit logging system.

The screenshots provide visual evidence of:

- AWS network infrastructure and subnet configuration.
- Bastion host access to the private application server.
- EC2 application service and backup automation.
- IAM permissions and S3 upload restrictions.
- Backup archives stored in Amazon S3.
- Lambda execution and DynamoDB audit records.
- S3 Gateway VPC Endpoint functionality without a NAT Gateway.
- AWS Budget configuration.

Sensitive account information and infrastructure identifiers have been excluded or obscured from publicly shared screenshots.
